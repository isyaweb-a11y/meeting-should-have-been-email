## The entry

> The agenda said 'quick sync.' It was an email, read aloud slowly, by nine people who had already read it.

105 characters, one line. The joke skips the obvious complaint and lands on the absurd image instead: the meeting's whole purpose was an email, performed out loud, slowly, to an audience that had already read it.

## How it works

`main.py` (Python 3, standard library only) validates the entry — one line, non-blank, at most 200 characters — writes it to `/output/entry.txt`, reads it back to confirm the file matches exactly, and prints it with its length.

Run it:

```bash
python3 main.py
```
